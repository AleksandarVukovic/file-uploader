# Architecture Decision Records

This directory records the significant architectural decisions made in this project, and the reasoning behind them.

## Format

Each ADR follows a lightweight structure:

- **Status** — proposed, accepted, superseded, etc.
- **Context** — the problem or constraint that prompted the decision.
- **Decision** — what was decided.
- **Consequences** — trade-offs, follow-on effects, what this rules out.

## Numbering

Files are named `NNNN-title-with-dashes.md`, numbered sequentially in the order they were adopted. Numbers are never reused, even if a decision is later superseded — add a new ADR and mark the old one as superseded instead of editing history.
